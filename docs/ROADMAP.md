# Roadmap — MVP GarquinsFilm

## Fase 0 — Base documental y decisiones
PRD, flujos, modelo lógico, arquitectura, stack, despliegue inicial y criterios de aceptación. **Salida:** decisiones técnicas aprobadas.

## Fase 1 — Bootstrap y cuentas
Monorepo, CI básico, base de datos, migraciones, cuentas individuales y acceso por invitación. **Demo:** dos usuarios pueden acceder de manera aislada.

## Fase 2 — Catálogo y biblioteca
Conector TMDB, búsqueda, ficha, pendientes/vistas, favoritas, notas y orden/filtros. **Demo:** dos notas distintas para un mismo título.

## Fase 3 — Temporadas y listas
Seguimiento de temporadas, creación de listas, miembros y operaciones compartidas con permisos. **Demo:** lista conjunta con progreso individual.

## Fase 4 — Descubrir y estabilizar
Rankings externos, mejores por género, QA responsive, accesibilidad, documentación de despliegue y backups. **Demo:** Top 5 reproducible y acciones rápidas.

## Después del MVP
Seguimiento de episodios, estadísticas avanzadas, recomendaciones personalizadas (revisar licencias), «Sorpréndeme», notificaciones, importaciones y app nativa si se justifica.
